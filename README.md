# offline-mesh

An open-source, offline-first communication hub and local file transfer system built for emergency zones, offline environments, and low-connectivity scenarios.

## Features
- **Offline Bulletin Board:** Broadcast real-time message updates across open browser tabs/windows without active internet access.
- **Local File Transfer:** Share and download files directly in-browser using base64 encoding and local storage.
- **Zero Configuration:** Pure HTML5, CSS3, and JavaScript—no Node.js or server installation required[cite: 1].

## How to Run Offline
1. Clone or download this repository[cite: 1].
2. Open `index.html` in any modern browser[cite: 1].
3. Open a second tab or window to test live peer-to-peer messaging and file distribution[cite: 1].
