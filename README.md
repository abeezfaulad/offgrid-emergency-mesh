# offline-mesh

An open-source, zero-dependency emergency local hub designed for power blackouts, natural disasters, and zero-connectivity environments[cite: 1].

## Core Features
- **Offline Survival Knowledge Base:** Built-in searchable database for First-Aid, CPR, and Water Purification without active internet access[cite: 1].
- **Local Mesh Broadcast:** Instant peer-to-peer bulletin board updates across open browser instances via Web `BroadcastChannel`.
- **Offline QR Data Transfer:** Convert emergency updates into scanned QR codes to transfer data device-to-device offline.
- **Local File Distribution:** Upload and download binary files directly in the browser using base64 data encoding.
- **Service Worker PWA:** Fully cached client app accessible with zero network connection[cite: 1].

## Quickstart
1. Clone this repository[cite: 1].
2. Open `index.html` in any web browser.
3. Open a second tab to test multi-tab peer messaging or scan the generated QR codes directly with your mobile phone camera completely offline!
