# Contributing to OffGrid Emergency Mesh

Thanks for your interest. Here's how you can help.

---

## Report bugs

Open an issue with:

- What happened
- Steps to reproduce
- Your system (OS, Node.js version, browser)

---

## Suggest features

Open an issue with:

- What you want to add
- Why it's useful

---

## Submit code

1. Fork the repo
2. Create a branch: `git checkout -b feature-name`
3. Make your changes
4. Test locally: `npm install && node server.js`
5. Commit: `git commit -m "Description of changes"`
6. Push: `git push origin feature-name`
7. Open a pull request

---

## Code style

- Use 2 spaces for indentation
- Keep it simple and readable
